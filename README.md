## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Episode Tracker** | Track each episode from recording through editing to publish |
| **Transcript Log** | Note transcript edit status and key edit decisions per episode |
| **Show Notes** | Draft and organize show notes and chapter markers per episode |
| **Guest Manager** | Track guest bookings and interview topic notes per episode |
